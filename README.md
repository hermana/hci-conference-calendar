# hci-conference-calendar

A tool for keeping track of Human-Computer Interaction Conference dates and submission deadlines.

Built with [Next.js](https://nextjs.org).

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18.18 or later

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. The page auto-updates as you edit files under `src/app`.

### Other commands

```bash
npm run build   # build for production
npm run start   # run the production build locally
npm run lint    # lint the project
```
